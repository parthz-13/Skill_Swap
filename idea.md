**1. Project Title**
*Skill Swap - Peer-to-Peer Learning Platform for Students*

---

**2.Name & Roll Number**

---

**3. Problem Statement**

Students possess diverse skills and talents but lack a structured platform to share knowledge with peers. Traditional learning often relies on formal courses or expensive tutors, missing opportunities for collaborative peer-to-peer learning. Many students want to learn new skills but cannot find accessible ways to connect with knowledgeable peers on campus.

---

**4. Proposed Solution / Idea**

Skill Swap is a mobile application that enables students to exchange skills through a barter system of knowledge. Students can offer their expertise in certain areas and request to learn new skills from others, creating a collaborative learning community. The platform facilitates connections, scheduling, and communication between students, fostering both skill development and campus networking.

---

**5. Key Features**

* User profile creation with skills offered and skills wanted to learn
* Skill discovery and browsing system with search functionality  
* Request system for initiating skill swap exchanges with other users
* Real-time in-app messaging for coordination and communication
* Secure user authentication and profile management
* Session scheduling and management between skill exchange partners

---

**6. Target Users / Audience**

College and university students who want to learn new skills, share their expertise, and build connections within their campus community.

---

**7. Technology Stack**

* **Frontend:** React Native (Expo), React Navigation, Native Base UI
* **Backend:** Node.js, Express.js
* **Database:** MySQL 
* **Authentication:** JWT (JSON Web Tokens), bcryptjs
* **Real-time Communication:** Socket.io

---

**8. Expected Outcome**

A fully functional cross-platform mobile application where students can create profiles, browse available skills, send swap requests, and communicate in real-time. Users will be able to successfully connect with peers, schedule skill exchange sessions, and build a thriving learning community on campus.
